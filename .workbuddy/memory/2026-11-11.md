# 2026-11-11

## 网卡管理器（Delphi 12.3）
- 基于 workspace 内的 uNetworkConnection.pas（Network Connections COM：INetConnectionManager / EnableConnection）开发了网卡管理工具。
- 新增文件：NetworkMonitor.dpr、uMainForm.pas、uMainForm.dfm（均已加 UTF-8 BOM）。
- 功能：TListView 列出所有物理+虚拟网卡（名称/设备/状态/类型/IP/GUID），2 秒定时自动监测状态，选中后可启用/禁用（双击切换），操作需管理员权限（启动时提示提权重启）。
- IP 列通过 iphlpapi 的 GetAdaptersInfo 按 GUID 匹配获取。
- 用户需在 Delphi 12.3 中打开 NetworkMonitor.dpr 编译运行。
- 修复：IP 列全空的 bug——LoadIPMap 原先用 GetAdaptersInfo(nil, BufLen) 探测缓冲区大小，部分系统返回 ERROR_INVALID_PARAMETER 且不设置 BufLen 导致直接退出；改为先分配 16KB 初始缓冲区、溢出时按实际大小重试（官方推荐方式）。无 IP 的连接显示占位符"无 IP，未连接或已禁用"。
- 新增"网卡类型"列（GUID 移到 SubItems[5]）：取 GetAdaptersInfo 的 IFTYPE 字段映射（以太网/Wi-Fi/环回/隧道/PPP/WWAN 等），并结合驱动描述关键字（TAP/VMware/Hyper-V/Wintun 等）标注"· 虚拟"；已禁用等取不到的连接退回 NetCon 媒体类型推断。
